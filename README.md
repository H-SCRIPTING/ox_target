# HS ox_target — UI Redesign

A modern visual redesign of `ox_target` for FiveM.

This project keeps the original ox_target targeting functionality while replacing the default interface with a cleaner, more modern and responsive UI.

## ✨ What's Changed

### 🎨 Complete UI Redesign
- Modern dark UI
- Clean blue accent styling
- Rounded interaction cards
- Custom central targeting eye
- Dedicated option icons
- Improved spacing and typography
- Subtle borders, shadows and visual depth

### 🖱️ Improved Interaction
- Clear hover states
- Smooth option transitions
- Visual feedback when a target is detected
- Cleaner option hierarchy
- Easier to read while playing

### 📱 Responsive Layout
The interface uses responsive sizing so the target options adapt across different screen resolutions.

### 🔧 Core Functionality Preserved
This redesign focuses on the UI rather than replacing the targeting system itself.

The underlying ox_target targeting functionality remains intact, including:

- Entity targeting
- Vehicle targeting
- Ped targeting
- Object targeting
- Zones
- Target options
- Bone targeting
- Distance checks
- Groups & item checks
- `canInteract`
- Nested menus
- qtarget compatibility
- Existing exports/events

## 🆚 Standard ox_target vs HS Redesign

| Standard ox_target | HS Redesign |
| --- | --- |
| Minimal default interface | Modern custom interface |
| Basic eye indicator | Custom styled targeting eye |
| Simple option bars | Rounded option cards |
| Basic hover effect | Animated hover interaction |
| Minimal visual hierarchy | Clear icon + label hierarchy |
| Fixed-style presentation | Responsive sizing |
| Default typography | Modern Inter typography |
| Basic visual styling | Custom borders, shadows and accents |
